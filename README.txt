## ABOUT THE PROJECT

A thoughtfully designed interactive wedding invitation celebrating the union of Winston and Almira.

Created with elegant typography, delicate visual elements, and interactive features to provide guests with a memorable digital invitation experience.

## PROJECT FEATURES

- Interactive envelope opening
- Wedding invitation card animation
- Wedding countdown
- Calendar and event information
- Background music and interactive elements
- Responsive wedding invitation design

## TECHNOLOGIES

## PROJECT STRUCTURE

| File / Folder | Description |
|---|---|
| `index.html` | Page content, names, venues, dates, and text |
| `css/style.css` | Colors, layouts, and visual styling |
| `js/script.js` | Countdown, calendar, envelope opening, and interactions |
| `images/` | Flowers, envelope layers, invitation card, and wax seal |
| `fonts/` | Bundled fonts used throughout the invitation |

## CUSTOMIZATION GUIDE

| Element | Where to Edit |
|---|---|
| Wedding date / countdown | Search `2027-01-21` in `js/script.js` |
| Names, venues, and text | `index.html` |
| Colors | `:root` block in `css/style.css` |
| Seal position | `.seal` top/left in `css/style.css` |
| Invitation card rise height | `#env.opening .invite` transform in `css/style.css` |

## TYPOGRAPHY

| Element | Font |
|---|---|
| Names and subheadings | Ballet |
| Section headings | Pinyon Script |
| Body text and dates | Cormorant Garamond |

All fonts are bundled in the `fonts/` folder, allowing the invitation to work offline.
